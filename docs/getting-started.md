# Getting Started

1. Make your Google Form public (no sign-in required).
2. Get its field ids: `npx @ez-gform/cli <google-form-url>`
   ([CLI docs](../packages/cli/README.md)).
3. Pick how you submit:
   - **React** — `pnpm add @ez-gform/react`, see the
     [react README](../packages/react/README.md).
   - **No framework** — `pnpm add @ez-gform/core`, see the
     [core README](../packages/core/README.md).

Prefer clicking around? Run the docs site with
`pnpm --filter @ez-gform/docs dev` and open `/playground`.
