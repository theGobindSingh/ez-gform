# @ez-gform/extension

The `ez-gform` browser extension: point it at a Google Form and get a paste-ready
JSON schema, TypeScript types, React component, or plain HTML `<form>` with
`entry.NNN` field names already filled in.

This package doesn't contain extension logic itself - it assembles the
already-built outputs of `@ez-gform/background`, `@ez-gform/content-script`,
and `@ez-gform/popup` into `dist/`, and writes `manifest.json`.

## Build

```sh
pnpm turbo run build --filter=@ez-gform/extension
```

This builds the three sibling packages first (Turbo's `^build` dependency),
then runs `src/index.ts` to copy their outputs into `packages/extension/dist/`
and generate `dist/manifest.json`.

## Load unpacked - Chrome

1. Run the build above.
2. Open `chrome://extensions`.
3. Enable "Developer mode" (top right).
4. Click "Load unpacked" and select `packages/extension/dist`.
5. Open any `https://docs.google.com/forms/...` page (editor or published) and
   click the ez-gform icon in the toolbar.

## Load unpacked - Firefox

This extension currently ships **Chrome-only manifest** (MV3
`background.service_worker`). Firefox's MV3 support for service workers is
still incomplete as of this writing; Firefox instead expects
`background.scripts` (a non-module background page) unless run under a
`browser_specific_settings.gecko` override with the newer `service_worker`
support enabled in about:config. This package does **not** currently generate
a Firefox-specific manifest variant, so loading `dist/` via
`about:debugging#/runtime/this-firefox` -> "Load Temporary Add-on" is expected
to fail or behave differently until a Firefox variant is added. Treat this
extension as Chrome-only (and Chromium-based browsers - Edge, Brave, etc. -
which share Chrome's MV3 implementation) for now.

## Package outputs it depends on

| Package                           | Built file(s)                                                   | Copied to                                           |
| --------------------------------- | --------------------------------------------------------------- | --------------------------------------------------- |
| `@ez-gform/background`            | `dist/background.js`                                            | `dist/background.js`                                |
| `@ez-gform/content-script`        | `dist/content-script.js`                                        | `dist/content-script.js`                            |
| `@ez-gform/popup`                 | `dist/index.html`, `dist/popup.js`, `dist/assets/*`             | `dist/popup.html`, `dist/popup.js`, `dist/assets/*` |
| `packages/extension/static/icons` | 16/32/48/128px PNGs (generated by `scripts/generate-icons.mjs`) | `dist/icons/*`                                      |

## Scripts

- `pnpm dev` - `tsx scripts/watcher.ts`: watches `src/`, and the sibling
  packages' `node_modules` symlinks, and re-runs the assembler on change.
- `pnpm build` - one-shot assembly (see above).
- `pnpm zip` - packages `dist/` into `ez-gform-extension-<version>.zip` for
  upload to the Chrome Web Store; uses the system `zip` CLI if present, and a
  small built-in fallback zip writer if not.
- `pnpm test` - Vitest unit tests for the pure manifest-building logic.
