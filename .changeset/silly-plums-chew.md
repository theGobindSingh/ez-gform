Initial release of `@ez-gform/react`: `useGoogleForm`, a controlled-values hook with an explicit `idle`/`validating`/`submitting`/`sent`/`ok`/`error` status machine, promise-returning `submit`, schema-driven validation, and `register`/`registerCheckbox` field bindings; plus `useEasyGoogleForm`, a deprecated drop-in compat shim for the legacy `formRef`/`gFormId`/`links` API that now resolves a `SubmitResult` instead of firing and forgetting.
